# Power BI Sales Analysis Dashboard

## Overview
This project demonstrates a Sales Analysis Dashboard created using Power BI. It provides insights into sales performance across regions, product categories, and customer segments.

## Features
- Donut Chart for regional sales distribution.
- Funnel Chart for sales by product sub-categories.
- Map Visual for state-wise sales.
- Pie Chart for regional sales performance.

## Tools Used
- Power BI for data visualization.
- Excel for data preparation.

## How to Use
1. Download the `.pbix` file.
2. Open it in Power BI Desktop to explore the dashboard.
